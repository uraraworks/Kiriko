実素材 `PXL_20251001_021741207.ACTIVE.TS.mp4`（HEVC 1080p / 14GB）の先頭 90 秒を切り出して検証。

| 映像内容 | in 点のフレームが元素材と一致 |
| 音声 | max_volume が元素材と一致（-5.9 dB） |

## プロジェクト JSON

AI が直接読み書きできることを狙った素直な構造。`telops` / `audioClips` / `blurs` は
Phase 2・3 用に枠だけ用意してある。

```json
{
  "version": 1,
  "output": { "width": 1920, "height": 1080, "fps": 30, "videoBitrate": 12000000 },
  "sources": [{ "id": "src_x", "name": "PXL_....mp4", "duration": 5400.0 }],
  "clips":   [{ "id": "clip_x", "sourceId": "src_x", "in": 12.5, "out": 18.2, "volume": 1 }]
}
```

### 作業フォルダ（VSCode 方式）

ブラウザにはパスの概念が無い。`File` にも `FileSystemFileHandle` にも
**親フォルダへ辿る手段が無い**ので、「プロジェクトファイルの隣にある動画」には原理的に届かない。
そこで VSCode と同じく、**フォルダごと開いてもらう**。

ツールバー左端の 📁 で `showDirectoryPicker({ mode: 'readwrite' })` を出し、
ハンドルを IndexedDB（`dirHandles` の `__work__`）に保存する。

- フォルダ直下の `*.kiriko` を探し、1 つならそのまま開く／複数なら選ばせる
- 保存はこのフォルダへ直接書く（`showSaveFilePicker` を出さない）
- 素材の名前引きは、覚えているフォルダの中でも**作業フォルダを最優先**で探す
- ライブラリのテロップを置いた時、同梱画像をこのフォルダへ実ファイルとして書き出す

素材ファイルそのものは JSON に入らないが、**一度開いたファイルは次から自動で読み直す**。
File System Access API のハンドルを IndexedDB に覚えておき、プロジェクトを開いた時に
名前で引いて復帰させる（ファイル選択でもドロップでも覚える）。

見つからない素材があれば上部に帯が出て、**［素材を探す］**（覚えている物の読み直し＋選択）か
**［フォルダを選ぶ］**（作業フォルダとして覚え、その中を名前で探す）で解決できる。

画像だけは、実ファイルが見つからなくても**テロップライブラリの中から同じ名前のものを探す**。
ライブラリから置いたテロップの画像は、元ファイルが手元に無いことがあるため。

> これはあくまで保険で、**ライブラリからそのセットを消すと効かなくなる**。
> ただし作業フォルダを開いていれば、ライブラリのテロップを置いた時点で
> 画像がそこへ実ファイルとしてコピーされるので、保険に頼らずに済む。

保存時の拡張子は `.kiriko`（中身は JSON）。

## テロップ（Phase 2）

Keynote → PNG 書き出しの運用を置き換えるのが目的。1 文字直すのに書き出し直す必要はない。

### テロップは「セット」

1 枚の PNG に焼いていたものを、そのまま構造として持てるようにしてある。

- **複数行**：行ごとに書体・大きさ・色・縁・横の寄せを変えられる（見出し＋日時、のような組み）
- **背景画像**：枠に敷く。帯やフレームの PNG をそのまま使える
- **アイコン画像**：文字の左右上下に添える（ロゴなど）。位置・大きさ・間隔・縦位置を指定
  - 透明な余白は自動で切り詰めるので、1920×1080 の中に小さく置かれたロゴでもそのまま使える
- セットごと移動・リサイズ・時間調整でき、書き出しにもそのまま焼き込まれる

### トラック

テロップは **T1 / T2 …** と重ねられる（A1 / A2 と同じ考え方）。
動画全体に出す見出しを T1、途中で入れるものを T2、のように分けると掴みやすい。
新しいテロップは同じ時間に重ならないトラックへ自動で入り、縦にドラッグすれば移せる。

### ライブラリ（プロジェクトをまたいで使い回す）

テロップダイアログ下部の **［★ ライブラリに保存］** で、背景画像・アイコンごと保存する。
画像を含むセットの保存時、ライブラリフォルダが未設定または許可切れなら確認を出す
（`ensureLibDir`）。`.kirikolib` の書き出しは、実ファイル参照のままの軽い形式と、
画像を埋め込む可搬な形式を選べる。
左パネルの **テロップ** タブから、別のプロジェクトでもそのまま呼び出せる。

保存先はブラウザの IndexedDB。**ライブラリフォルダ**（`dirHandles` の `__lib__`）を決めてあれば、
画像はそこへ実ファイルで置き、ライブラリには `{ name, file: true }` だけを持たせる
（IndexedDB を膨らませない・`.kirikolib` も小さくなる）。決めていない場合は
画像を dataURL で同梱するので、素材の無いプロジェクトでも
呼び出した時に自動でビンへ読み込み直す（同名の画像が既にあればそれを使う）。

**ライブラリ自体はオリジンごと・ブラウザごと**に分かれる（localhost と GitHub Pages でも別）。
移したい時は テロップタブの **［書き出し］／［読み込み］** で `.kirikolib` にまとめられる
（画像も入るのでこれ 1 つで完結する）。同じ名前・同じ中身のものは重複して入らない。

- **二重縁取り**：外の白フチ（`outerStroke` × `outerScale`）＋ 内側の濃い縁（`stroke`）＋ 塗り（`fill`）＋ 影
- **改行対応**：テキスト欄で改行するとそのまま複数行になる
- **枠で位置と大きさを決める**：プレビュー上の枠をドラッグで移動、四隅・辺のハンドルで大きさ変更。
  枠の中での**横の寄せ**（左 / 中央 / 右）と**縦の寄せ**（上 / 中央 / 下）を指定でき、
  枠の幅で自動折り返しもする
- **吸着と画面外防止**：移動もリサイズも画面の端・中央・セーフマージンに吸着し（<kbd>Alt</kbd> で解除）、枠は画面外へ出ない
- **つまみをダブルクリック**：枠を文字の大きさにぴったり詰める
- **カーソルキー**：プレビューをクリックしてから <kbd>←</kbd><kbd>→</kbd><kbd>↑</kbd><kbd>↓</kbd> で 1px（<kbd>Shift</kbd> で 10px）移動
- **編集はポップアップ**：テロップを選ぶと編集ダイアログが開く。ヘッダをつかんで好きな位置へ動かせる
- **プリセット**：スタイルと位置をセットで保存。既定で「実況（下段中央）」「金額（右上）」「見出し」「注釈」を用意
- **タイムライン**：T1 トラックで表示時間をドラッグ／端ドラッグでトリム。
  **カットの切り替わりに吸着する**（<kbd>Alt</kbd> で解除）
- **フォント 3 ルート**
  - 内蔵 Web フォント（M PLUS Rounded / ロックンロール One / デラゴシック / 油性マジック / Kiwi Maru）
  - 「PC のフォント一覧」＝ Local Font Access API でインストール済みフォントを列挙
  - 「.ttf を追加」＝ 手持ちのフォントファイルを読み込み

プレビューと書き出しは `js/telop.js` の **同じ描画関数**を通るので、見たままが焼き込まれる。

**下線と取り消し線は canvas に無い**ので自分で矩形を引く。文字と同じ
「外フチ → 内縁 → 本体」の重ね方にするが、**フチの太さは線に合わせて縮める**
（文字と同じ太さにすると帯になって文字を潰す）。位置は文字の左端から
`inkWidth` ぶんで、寄せの補正（`alignShift`）を戻して求める。

太字・斜体・下線・取り消し線は**独立**（排他ではない）。太字＋斜体はよくある組み合わせ。

**背景画像・アイコン・文字の自由配置**は、**テロップの枠の左上からの相対**で持つ
（`bgBox` / `icon.x,y` / `textX,textY`）。文字は「文字を流し込む領域ごとずらす」形なので、
寄せ（`hAlign` / `vAlign`）や折り返し幅はそのまま効く。絶対座標にしなかったのは、枠を動かした時に画像が付いてこないと
「セット」として扱えなくなるため。左上を基準にしたのは、他の座標（`box`・画像クリップ）が
すべて左上基準で揃っていることと、枠を右下方向にリサイズしても位置がずれないため。
寄せ配置から切り替えた瞬間は、その時点で見えている位置と大きさを引き継ぐ（飛ばない）。

**フォント一覧は自前で描く**（`openFontPicker`）。`<select>` の `<option>` に
`font-family` を指定しても、macOS の Chrome はネイティブのポップアップで描くため
反映されないことがある。「どんな字か見て選ぶ」を確実にしたいので独自にした。

**一覧に載らないフォント**もある（macOS があとからダウンロードするものなど、
`queryLocalFonts()` が返さないのに CSS からは使える）。名前を直接入れる欄を用意し、
`fontAvailable()` で実際に使えるか測ってから受け付ける。
測り方は「serif と monospace という形の違う代替を指定して幅を比べ、
同じなら代替に落ちていない＝その書体が使われている」。

**日本語のフォント名**は、Local Font Access API が英語名しか返さないため、
フォントファイルの `name` テーブルから自分で読む（`js/fontname.js`）。
ファイル全部は読まない — ヘッダを 16 バイト読んでテーブル一覧の位置を求め、
`name` テーブルだけ `Blob.slice()` で切り出す（1 フォント数 MB × 数百個あるため）。
nameID 16（推奨ファミリ名）を 1 より優先し、Windows(3)/langID 0x0411 と
Mac(1)/langID 11 の両方を見る。

**字間**（`letterSpacing`）は行ごとの書式。canvas の `ctx.letterSpacing` を使う。
`measureText` は**最後の文字のうしろにも字間を足した値**を返すので、
寄せる時はその分を引く（`inkWidth` / `alignShift`）。引かないと、
中央寄せで字間の半分だけ左にずれる。測るだけの関数は `save`/`restore` で挟んで、
共有の ctx に字間を残さない。

> テロップの時刻は**出力タイムライン基準**。カットやトリムで長さが変わった分は
> [リップル](#カットに合わせて後ろを詰めるリップル)で一緒に動くが、
> クリップの**並べ替え**には追従しない。

## 音まわりとぼかし（Phase 3）

**トラック構成**：MK（マーカー）／FX（ぼかし）／IM（画像）／T1・T2…（テロップ）／
V1（映像）／A1（素材音）／A2・A3…（効果音・BGM）。

テロップと音源は **T1 / T2**、**A2 / A3** と重ねられる。BGM を流しながら効果音を 2 種類
同時に鳴らす、といった使い方ができる。新しく置いたものは同じ時間に重ならないトラックへ
自動で入り、縦にドラッグすれば移せる。空きトラックは常に 1 本下に出る。

タイムラインの高さは上端の**スプリットバー**で変えられる（記憶する）。
入りきらない時は縦にスクロールする。

- **効果音 / BGM**：mp3 をドロップするとビンに入る。ビンの ＋ で再生位置に配置。
  尺 20 秒超は BGM とみなして音量 35%・フェードイン 1.5 秒／アウト 2 秒の既定値が付く
- **クロスフェード**：BGM を重ねて置き、それぞれにフェードを付ける。タイムライン上では台形で見える
- **音量**：クリップ単位／音源クリップ単位に加えて、**効果音と BGM の全体音量**（インスペクタ「音量（全体）」）。
  素材の効果音が大きすぎる時は全体音量で一括して下げられる
- **ループ**：BGM を素材より長い尺にすると、頭に戻って指定した終了位置まで繰り返す
- **尺の調整**：タイムライン上で端をドラッグ。頭側を詰めると素材の頭出し位置も一緒にずれる
- **ぼかし**：プライバシー保護用。強さ 4〜120px。**全画面**と**部分（顔など）**を選べる
  - 全画面は、縁が透明を巻き込んで暗くならないよう、ぼかし半径ぶん拡大して描いてから切り取る
  - 部分ぼかしは楕円（矩形も可）。縁は外へ向けて薄くなるので四角い境目が出ない
  - **追従（キーフレーム）**：要所で位置を打つと間を線形補間する。動く顔に追えるようにするため
  - プレビュー上で枠をドラッグして位置と大きさを決められる（テロップ・画像と同じ操作。
    クリックで選択、四隅・辺で拡大縮小、カーソルキーで 1px、端と中央に吸着、アンドゥも効く）
  - プレビューにも実際に掛かった状態が出る（`<video>` の CSS filter では部分ぼかしを
    表現できないので、その区間だけ映像をキャンバスに描き直して重ねている）
  - テロップはぼかしの**上**に描かれるので読みやすさは保たれる

プレビューの音は Web Audio でスケジュール再生する。クリップ跨ぎのシークでは
鳴らし直さず（BGM が切れるため）、ずれが 0.25 秒を超えた時だけ組み直す。

## 書き出し（mp4）

書き出しボタンを押すと**先に保存先を聞き**、`FileSystemWritableFileStream` へ
**エンコードしながら直接書き込む**。数 GB でもメモリには載らない。
`showSaveFilePicker` が無いブラウザだけ、メモリに溜めて最後にダウンロードする。

H.264 のレベルは解像度とフレームレートから選ぶ（`pickAvcCodec`）。
4.0 固定だと 1440p 以上で `configure` が失敗するため。`isConfigSupported` で確かめてから使う。

mp4 の索引（moov）は**ファイル先頭**に置く（faststart）。末尾だと Web に置いた時の
再生開始が遅れるため。ディスクへ直接書く場合は先に場所を空ける必要があるので、
`fastStart: {expectedVideoChunks, expectedAudioChunks}` に **総尺から見積もった数 × 1.2 + 1000** を渡す。
足りないと書き出しの最後で失敗するので多めに取る。余りは `free` ボックスで埋まる。

実際の出力（12 秒・1080p30）の箱の並び:

```
ftyp:28  moov:4837  free:88827  mdat:3661495
```

## カットに合わせて後ろを詰める（リップル）

クリップの長さが変わったら、テロップ・画像・ぼかし・音源・マーカーも同じだけ動かす。
完成間近で頭を数秒切った時に、全部を手で置き直さずに済ませるため。

| 操作 | 動き |
|---|---|
| 範囲を切り取る（I→O→Delete） | `rippleAfter(a,b)`。範囲内のものは消す |
| クリップを削除 | そのクリップの占めていた区間で `rippleAfter` |
| クリップの端をドラッグ | 縮めた分は `rippleAfter`、伸ばした分は `insertGapAt` |
| クリップの並べ替え | 動かさない（どこに合わせるべきか決まらないため） |

`insertGapAt` は境目をまたいでいるものだけ終わりを伸ばして、掛かり続けるようにする。

## コピー / 貼り付け

テロップ・音源・画像・ぼかしは <kbd>⌘C</kbd> / <kbd>⌘V</kbd> で複製できる。
貼り付け先は**再生位置**。長さ・書式・音量はそのままで、id だけ振り直す
（`S.clipboard` に JSON のディープコピーを持つ）。
テロップ 1 つだけの時は貼り付け後に編集ダイアログが開く（数字だけ直す使い方を想定）。

**複数まとめて**は範囲選択（<kbd>I</kbd>〜<kbd>O</kbd>）で行う。範囲がある状態で <kbd>⌘C</kbd> すると、
そこに掛かっているテロップ・音源・画像・ぼかしが全部入る。個別の複数選択は持たせていない
（選択状態を増やすと削除や移動の意味が曖昧になるため、既にある範囲選択に寄せた）。

貼り付けの基準は**いちばん早いもの**。それが再生位置に来て、残りは元と同じ間隔で並ぶ。
範囲の取り方（どこに I を置いたか）で結果が変わらないようにしている。
右クリックメニューからも同じ操作ができる。

## アンドゥ / リドゥ

プロジェクトが JSON なので、スナップショットを丸ごと積む方式（`js/history.js`）。
200 カット規模でも 1 スナップショット数十 KB なので、差分管理はしていない。最大 100 段。

- ドラッグやスライダーのような**連続する操作は 1 エントリにまとまる**。
  20 回文字を打っても、30 回スライダーを動かしても、アンドゥ 1 回で戻る
  （`commit(label, key)` の key が同じ間はまとめ、pointerup / フォーカス移動で区切る）
- 戻す・進むボタンのツールチップに「元に戻す：3.00 をカット」のように**操作名が出る**
- 素材と音源の読み込みは履歴の対象外。巻き戻しで読み込み済みメディアが消えないよう、
  スナップショット復元時に再マージしている

## 画像

「＋ 画像」または png / jpg のドロップで読み込む。ビンのサムネイル下にある
**全画面 / 画面上 / 画面中央 / 画面下 / 画面左 / 画面右** から配置する。

- 出力と同じ比率の画像（1920×1080 のテロップ用 PNG など）は、追加時に自動で**全画面**になる
- それ以外（縦長のスクリーンショットなど）は**中央**に収まる大きさで入る
- テロップと同じ枠なので、ドラッグ移動・ハンドルで拡大縮小・カーソルキーで 1px 調整ができる。
  角のハンドルは <kbd>Shift</kbd> を押しながらで比率を保つ
- **つまみをダブルクリック**：枠を画像の大きさにぴったり合わせる（`contain` の余白が消える）
- **画像をダブルクリック**：等倍（100%）に戻す。等倍で画面からはみ出す場合は収まる大きさまで縮める
- **右クリック**：削除メニューを出す（ブラウザ標準の「全て選択」等は出さない）

## タイムラインの見た目

- **サムネイル**：V1 にフィルムストリップを出す。1.5 時間ぶんを先に作るのは無理なので、
  **画面に見えている範囲だけ**を 1 枚ずつ遅延生成してキャッシュする（表示範囲が変わったら
  未処理の要求は捨てる）。実測 1 枚 40ms 程度
- **波形**：A1 は素材の音声を 20 秒区間ごとに遅延デコードしてピークを貯める（50ms 刻み）。
  A2 の SE / BGM は AudioBuffer から即時に作る。無音区間が見えるのでカット位置を探しやすい
  - 素材ごとに**最大値で正規化**する。小さい音で録れていると等倍では平らに見えてしまうため
- どちらもタイムライン右上の **▣**（サムネイル）／**〜**（波形）で切り替えられる
- 見出し（MK / FX / IM / T1 / V1 / A1 …）は 2 文字なので、`TRACK_TIPS` の説明を `title` で出す
- プレビューのシークバーで飛んだ時は、表示範囲から外れていれば**拡大率を変えずに**寄せる
  （`revealPlayhead`）

## マーカー（メモ）

タイムライン最上段の **MK** トラック。<kbd>M</kbd> で再生位置に立てる。

- **点マーカー**：位置とメモだけ。<kbd>,</kbd> <kbd>.</kbd> で前後のマーカーへ飛べる
- **区間マーカー**：長さを付けると区間になる。左右どちらの端もドラッグで詰められる
  - 種別は **残す**（緑）／**消す**（赤）／**メモ**（黄）。
    「セリフの所に残す」でも「無音の所に消す」でも、同じ流れで処理できる
- **［区間外］**（<kbd>G</kbd> 次へ／<kbd>F</kbd> 前へ）：区間マーカーの**外側**（＝消す候補）を 1 つずつ範囲選択して、そこへ移動する

一番手間の掛かる「自分が喋っている所だけ残す」作業を狙った機能。
AI に「セリフが取れる箇所に、セリフをメモとして区間マーカーを立てて」と頼んでおき、

1. <kbd>G</kbd> で次の「区間外」へ飛ぶ（<kbd>F</kbd> で前に戻れる）
2. 中身を見て、必要なら範囲の端を詰める
3. <kbd>Delete</kbd> で切り取る

を繰り返す。**AI の区間が正確とは限らない**ので、まとめて消すより取りこぼしに気付ける。
（一括で消したい時は、マーカーを右クリック →「区間マーカーの外を全部切り取る…」）

マーカーの位置（区間なら両端）はドラッグの**吸着先**にもなる。
**再生位置のドラッグ**もカットの境目・マーカー・範囲の端に吸着する（<kbd>Alt</kbd> で解除）。
画像やテロップをカットの頭にぴったり合わせたい時に効く。

## ツールチップ

ブラウザ標準の `title` は出るまでが 1〜2 秒あり、**その時間は変えられない**。
0.5 秒で出したいので、`title` を `data-tip` へ退避して自前で出している
（読み上げ用に `aria-label` は残す）。遅延は `js/main.js` の `TIP_DELAY`。

タイムライン左端の見出し（MK / FX / IM / T1 / V1 / A1 …）は 2 文字で意味が分からないので、
`TRACK_TIPS` に説明を持たせて `title` に流している。

## 重ね順（Z オーダー）

画像とテロップは同じ重ね順の列に並ぶ。インスペクタ／テロップダイアログの
**［最前面へ］［最背面へ］** で入れ替える。

内部的には各要素が `z` という数値を持っていて、描画時に昇順で重ねるだけ。
「最前面へ」は最大値 +1、「最背面へ」は最小値 -1 を振るので、値がぶつからない。
旧いプロジェクトは画像 → テロップの順（従来の見た目）で `z` を補完する。

## ボタンの置き場所

**操作の対象で置き場所を決める**。同じ操作のボタンを何箇所にも置かない。

| 場所 | 対象 | 中身 |
|---|---|---|
| ツールバー | アプリ全体 | 作業フォルダ / 開く / 保存 / 戻す / 進む / ヘルプ / 書き出し |
| ソースモニター下 | ソース | IN・OUT 表示 ＋ クリップ追加 |
| タイムライン上部 | タイムライン | テロップ追加 ／ 範囲（開始 / 終了 / 切り取り / コピー / 貼り付け / 解除）／ 削除 ／ 表示切替 ／ 拡大縮小 |
| 左パネル | 追加するもの | メディア（素材を追加＋絞り込み）、エフェクト（ぼかし）、テロップ（ライブラリ） |

範囲まわりのボタンは**使える時だけ出す**。通常は［開始］だけを置いておき、
開始を打つと［終了］［解除］と範囲の表示が、範囲になると［切り取り］［コピー］が、
コピーすると［貼り付け］が出る。終了から打つことはまず無いので、
最初から並べていると迷うだけだった。

ボタンはアイコン＋ツールチップ。**書き出し**（主要動作）と**切り取り**（不可逆）だけは
誤操作を避けるためラベルを併記している。アイコンは外部依存を避けてインライン SVG
（`index.html` 冒頭の `<symbol>` 群）。ツールチップにはショートカットも入れてある。

## パネルの構成

**左（ビン）**

- **メディア**：**［素材を追加］1 つ**で読み込む（動画 / 音源 / 画像は拡張子で振り分ける）。
  その下の **すべて / 動画 / 音源 / 画像** は絞り込み。各行の **×** でプロジェクトから外せる
  （使っている場合は何がいくつ消えるかを確認する。⌘Z で戻せる）
- **エフェクト**：今はぼかしのみ。`js/main.js` の `EFFECTS` に足せば一覧に並ぶ
- **テロップ**：セットのライブラリ。ライブラリフォルダもここで決める

**右（インスペクタ）**

- **プロパティ**：選択中の要素（クリップ／ぼかし／音源／画像）。何かを選ぶと自動でこのタブに切り替わる
- **出力**：解像度（4K / WQHD / FHD / HD）・フレームレート・ビットレート・全体音量
- **メモ**：作業メモ

テロップだけはフローティングダイアログ側で編集する（プレビューのすぐそばで打てるように）。
ショートカット一覧はツールバーの **?**（または <kbd>?</kbd> キー）で開く。

## プロジェクトの保存先

`.kiriko` を開いたら、**ファイル名とハンドルを `S.projectFile` に覚える**。
保存はこの順に試す。

1. 開いたファイルのハンドルへ書き戻す（同じファイルが更新される）
2. 作業フォルダに、同じ名前で書く
3. `showSaveFilePicker` で聞く（選ばれた名前を以後の保存先にする）

タイトル（`project.title`）は中身の見出しであってファイル名ではないので、
**保存名は開いたファイル名を優先する**。タイトルが未設定のときだけファイル名から補う。

> 以前はタイトルだけを見て `${title}.kiriko` に保存していたため、
> 開いたプロジェクトを編集して保存すると `無題プロジェクト.kiriko` という別ファイルになっていた。

## Kdenlive の取り込み

`.kdenlive` は「開く」からでもドロップでも取り込める（既存プロジェクトのカット列を引き継ぐ）。
Kdenlive の作りに合わせて、以下を面倒みている。

- 1 トラックが内部に持つ 2 本の playlist を両方読む（片方だけだと取りこぼす）
- **映像トラックが複数ある場合は位置順に統合する**。実素材では V1 の隙間を V2 の
  クリップが埋めている作りで、V1 だけ読むと 12 クリップ落ちた
- `<blank>`（隙間）から各クリップのタイムライン位置を求めて並べ直す
- MLT の `out` は最終フレームなので、長さは `out - in + 1 フレーム`
- 重ねて置かれたクリップ（PinP 等）は Kiriko の 1 本の V1 では表せないので取り込まず、
  件数を知らせる

## MCP 連携（設計）

```
MCP クライアント ──stdio── mcp/server.js ──WebSocket(127.0.0.1:8910)── ブラウザの Kiriko
```

繋ぎ方と提供ツールの一覧は [`../mcp/README.md`](../mcp/README.md)、
ページ内 JS から直接叩く場合は [AUTOMATION.md](AUTOMATION.md)。ここは設計の記録だけ。

**方針**

- **動画そのものは外に出ない**。やり取りするのは編集内容の JSON と、
  明示的に要求された時のフレーム画像だけ。待ち受けは `127.0.0.1` のみ
- 書き込み系は Kiriko の履歴に積むので、**人間が <kbd>⌘Z</kbd> で戻せる**
- AI は下ごしらえまで。範囲の詰めと最終判断は人間が画面を見て行う
- `bme.call(cmd, args)` と MCP は**同じコマンド実装**を通る。経路で挙動がずれないようにするため

**GitHub Pages（https）に置いたものからでも繋がる** — localhost は安全なオリジンとして
扱われるため（Safari だけは塞いでいる）。この点は実機の Chrome で TCP レベルまで確認済み。

**想定する流れ**

```
「無音の所を調べて、消す候補としてマーカーを立てて」
  → kiriko_find_silence → kiriko_add_markers(kind: 'cut')
  → 人間が G / F で 1 つずつ確認して Delete
```

「セリフの所に keep」でも「無音の所に cut」でも、Kiriko 側は同じ流れで処理できる。

セリフの書き起こしは `whisper.cpp` をローカルで回す（音声はマシンから出ない）。
**無音には whisper をかけない** — 何も言っていない所に文章を作ってしまうため、
Kiriko の音量データで「音がある区間」だけを切り出して渡している。

## テスト

ビルドが無いぶん、壊れても実行するまで気付けない。3 層に分けて置いている。

| 層 | 場所 | 何を見るか | 時間 |
|---|---|---|---|
| 単体 | `test/unit/` | 計算とデータ構造（`edit` / `project` / `boxes` / `history` / `images` / `waveform` / `telop` / `exporter`） | 1〜2 秒 |
| 静的検査 | `test/static/` | 重複 id、`$('x')` の実在、未使用 id、SVG の参照先、リンク切れ、CSS 変数の未定義 | 1 秒未満 |
| 結合 | `test/e2e/` | 実 Chrome で読み込み→カット→テロップ→**実書き出し**まで。レイアウトの実測も | 1 分ほど |

```bash
npm test          # 単体＋静的検査。依存なしで走る（node --test だけ）
npm run test:e2e  # 結合。puppeteer-core ＋ システムの Chrome ＋ ffmpeg
npm run hooks:install   # push 前に npm test を通す git フックを入れる
```

**素材はその場で作る。** `test/.fixtures/` に ffmpeg で短い mp4 / mp3 / png を生成する
（`testdata/` は git 管理外なので、それに依存させない）。

**入口は `window.bme`。** 結合テストは MCP と同じコマンド経路を通るので、
テストのために別口を用意していない。作業フォルダのゲート解除も、
`showDirectoryPicker` だけ差し替えて実際の［作業フォルダを開く］を押している。

**DOMParser や Canvas が要るもの**（`kdenlive` / `telop` の描画系）は node では動かないので、
`test/e2e/modules.test.mjs` でブラウザの中から `import()` して検証する。

### この 3 層で捕まえた実際の退行

| 事例 | 捕まえる層 |
|---|---|
| `id="overlay"` の重複で書き出しダイアログが出ない | 静的 |
| 素材バーが消えるとタイムラインが 6px に潰れる | 結合（高さの実測） |
| `min-height:0` 忘れでダイアログのボタンが枠外へ | 結合（位置の実測） |
| H.264 レベル 4.0 固定で 1440p 以上が失敗 | 単体（`avcCodecCandidates`） |
| 並べ替えが同じ位置で振動する | 単体（`dropIndex` の総当たり） |
| Kdenlive の複数トラックを取りこぼす | ブラウザ内モジュール |
| 使わなくなった SVG シンボルが残る | 静的（未使用 id） |
